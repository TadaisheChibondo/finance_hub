# 💸 Finance Hub

**Finance Hub** is a comprehensive financial management application designed specifically for university students. It empowers students to track their offline budgets, access emergency micro-loans, and receive smart, data-driven financial insights.

---

## ✨ Key Features

- **📊 Live Dashboard:** A beautiful, dark-themed UI that tracks real-time wallet balances and active loan statuses.
- **🏦 Student Micro-Loans:** A fully integrated loan request system that checks eligibility, calculates interest, and writes directly to a live Supabase backend.
- **📉 Offline Budgeting:** Track daily expenses and manage weekly/monthly limits locally using a high-performance Hive database.
- **💡 Smart Insights:** Receive dynamic financial advice and alerts pulled directly from the cloud to encourage responsible spending.
- **🎨 Modern UI/UX:** Built with a custom color palette, smooth animations, and responsive layouts that look great on any device.

---

## 🛠 Tech Stack

**Frontend**

- **Flutter & Dart:** For cross-platform mobile development.
- **Provider:** For robust, scalable state management across the app.

**Backend**

- **Supabase (PostgreSQL):** Cloud database handling relational data for `students`, `micro_loans`, and `financial_advice`.
- **Hive:** Fast, lightweight NoSQL local storage for offline budgeting features.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Dart SDK
- An Android Emulator or physical device

### Installation

1. **Clone the repository:**

```bash
   git clone [https://github.com/TadaisheChibondo/finance_hub.git](https://github.com/TadaisheChibondo/finance_hub.git)
```

Navigate to the directory:

```Bash
cd finance_hub
Install dependencies:
```

```Bash
flutter pub get
Run the app:
```

```Bash
flutter run
(Note: The Supabase connection is pre-configured in main.dart for demonstration purposes.)
```
